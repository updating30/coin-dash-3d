# コインダッシュ3D

車で走ってコインを集め、対向車をよける3Dのミニゲームです。スマホのブラウザでそのまま遊べます。

**遊ぶ（ブラウザで開けます）**：https://updating30.github.io/coin-dash-3d/

## 遊び方

- 画面の左右をタップ（またはスワイプ）して、レーンを移ります。PCは ← → キー
- コインを取ると加点。続けて取るとコンボになり、5コンボごとに点数の倍率が上がります
- 対向車にぶつかるとゲームオーバー。ベストスコアはその端末の中にだけ保存されます（どこにも送られません）

## 作り方

AI（Claude Code）に日本語で頼んで作りました。Vite + React + Three.js。画像や音声のファイルは使わず、形は Three.js の図形、効果音はブラウザの中で合成しています。
